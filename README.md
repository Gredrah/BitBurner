# BitBurner Scripts

BitBurner is a [Steam Game](https://store.steampowered.com/app/1812820/Bitburner/) focused on gameplay automation and puzzle solving in a virtualized "hacking" scenario. The game has a very in depth API allowing very advanced set-ups. These are not advanced set-ups but just my personal scripts for you to use/review if you're trying to learn the game for yourself.
